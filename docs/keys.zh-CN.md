# 每个键做什么

[English](keys.md) · 由 `scripts/make-keys-doc.py` 根据默认布局生成，改了布局后重新运行即可。
程序里按 Fn+NumLock 打开的键位图显示的是同样的内容。

## Claude

### 基础层

| 键 | 功能 | 说明 |
|---|---|---|
| 旋钮 | 移光标 回输入框 | 转动：左右移一个字。按下：光标回到输入框。 |
| Esc | Esc | Esc。停止 Claude 回复，连按两次回退到之前的消息。 |
| Del | 删一个词 | 删除光标前的一个词（Option+退格）。 |
| Tab | 下一项 | Tab：跳到下一个按钮、链接或输入框。 |
| 退格 | 删一个字 | 删除光标前的一个字。 |
| M1 | Claude | 从任何地方切到 Claude。 |
| Num | 到开头 | 跳到整段文字或文件的开头（Command+↑）。 |
| / | 左一词 | 按词左移（Option+←）。 |
| * | 右一词 | 按词右移（Option+→）。 |
| − | 到结尾 | 跳到结尾（Command+↓）。 |
| M2 | ChatGPT | 从任何地方切到 ChatGPT。 |
| 7 | 未使用 | 不输入任何内容，防止误触。 |
| 8 | 上翻页 | 向上翻一页。 |
| 9 | 微调上滚 | 对话区小幅滚动，按住连续，不受光标和鼠标位置影响。 |
| + | 换行 | 换行但不发送（Shift+回车）。 |
| M3 | 轮换应用 | 在 Chrome、VS Code 之间轮换。 |
| 4 | 左移 | 光标左移一格。 |
| 5 | 空格 | 空格。 |
| 6 | 右移 | 光标右移一格。 |
| M4 | 按住 Command 层 | 按住：键盘一直按着 Command。加数字切会话，加回车稍后发送，转旋钮或按 M3 选择应用。 |
| 1 | 逗号 , | 输入英文逗号“,”，不受输入法影响。 |
| 2 | 下翻页 | 向下翻一页。 |
| 3 | 微调下滚 | 对话区小幅滚动，按住连续，不受光标和鼠标位置影响。 |
| 回车 | 发送 | 发送消息。 |
| Fn | Fn 层 | 按住进入 Fn 层：面板、会话和常用回复。按住时键盘同时按着 Shift，所以键位图能看出来。 |
| 0 | 语音 | 点一下开始、再点一下结束；或者按住说话、松开结束。 按住 M4 再按 0，可改用 Mac 系统听写。 |
| . | 撤销 | 撤销（Command+Z）。 |

### 按住 Fn

| 键 | 功能 | 说明 |
|---|---|---|
| 旋钮 | 亮度 背光开关 | 按住 Fn 转动：调背光亮度。按下：开关背光。 |
| Esc | 蓝牙 1 | 切到蓝牙设备 1。 |
| Del | 向右删词 | 删除光标右边的一个词。 |
| Tab | 上一项 | Shift+Tab：回到上一个按钮、链接或输入框。 |
| 退格 | 向右删字 | 删除光标右边的一个字。 |
| M1 | 切换麦克风 | 第一下打开麦克风列表，当前用的高亮；列表显示时再按，切到下一个。停手 3 秒列表自动关闭。菜单栏里也能直接点选。 |
| Num | 键位图 | 打开或关掉这张键位图，按 Esc 也能关。 |
| / | 继续 | 粘贴并发送“继续。” |
| * | 就这样做 | 粘贴并发送“可以，就这样做。” |
| − | 运行测试 | 粘贴并发送“运行测试，并修复所有失败的测试。” |
| M2 | 蓝牙 2 | 切到蓝牙设备 2。 |
| 7 | Side Chat | 打开侧边聊天问问题，主会话继续工作。 |
| 8 | 上个会话 | 切到上一个会话。 |
| 9 | 新会话 | 新建会话。 |
| M3 | 2.4G | 切到 2.4G 接收器。 |
| 4 | 更改 | 打开改动面板，看 Claude 改了什么。 |
| 5 | 模式菜单 | 打开模式菜单，再用主键盘的数字切到 Plan 模式（小键盘不再输入数字）。 |
| 6 | 终端 | 打开或收起终端。 |
| M4 | 切换窗口 | 切换同一应用的窗口（反向轮换）。 |
| 1 | 文件 | 打开文件面板。 |
| 2 | 下个会话 | 切到下一个会话。 |
| 3 | 关面板 | 关闭当前面板。 |
| 回车 | 立即发送 | 立即发送排队中的消息（Claude 里是 Send now，ChatGPT 里是 Steer）。消息还在输入框里的话，先把它排进队列。 |
| Fn | 已按住 | Fn 层。 |
| 0 | 顺便问 | 在输入框最前面打上 /btw 再开始语音：顺便问个问题，不打断 Claude 正在做的事。说完再按 0 结束、回车发送；也可以按住说话、松开结束。 |
| . | 重做 | 重做（Command+Shift+Z）：恢复刚撤销的操作。 |

### 按住 M4

| 键 | 功能 | 说明 |
|---|---|---|
| 旋钮 | 选择应用 | 按住 M4 转动：在应用切换器里左右挑选，松开 M4 切过去。 |
| 7 | 会话 7 | Command+7：跳到第 7 个会话。 |
| 8 | 会话 8 | Command+8：跳到第 8 个会话。 |
| 9 | 会话 9 | Command+9：跳到第 9 个会话。 |
| M3 | 下一个应用 | 在应用切换器里选下一个。 |
| 4 | 会话 4 | Command+4：跳到第 4 个会话。 |
| 5 | 会话 5 | Command+5：跳到第 5 个会话。 |
| 6 | 会话 6 | Command+6：跳到第 6 个会话。 |
| M4 | 已按住 | 键盘一直按着 Command。 |
| 1 | 会话 1 | Command+1：跳到第 1 个会话。 |
| 2 | 会话 2 | Command+2：跳到第 2 个会话。 |
| 3 | 会话 3 | Command+3：跳到第 3 个会话。 |
| 回车 | 稍后发送 | Claude 或 ChatGPT 正在干活时，消息等这一轮结束再发。 |
| 0 | 切换听写方式 | 在应用自带的语音输入和 Mac 系统听写之间切换，每个应用单独记住。 |

## VS Code

| Del | 不启用 | VS Code 里删词不起作用，防止误改内容。 |
| Tab | 不启用 | VS Code 里Tab 不起作用，防止误改内容。 |
| 退格 | 不启用 | VS Code 里删除不起作用，防止误改内容。 |

| 8 | 上翻页 | 向上翻一页。 |
| 9 | 上移一行 | 资源管理器里选上一个或下一个；编辑器里移一行。 |
| + | 下一个文件 | 按资源管理器里的顺序打开下一个文件，预览跟着换。 |
| M3 | 轮换应用 | 在 Chrome、VS Code 之间轮换。 |

| * | 聊天面板 | 开关右边的聊天面板（Copilot 等）。 |

| 7 | 源代码管理 | 打开源代码管理，看改了什么。 |

| 回车 | 最近文件 | 打开最近文件列表：9、3 或旋钮上下选，回车打开。 |
| Fn | 已按住 | Fn 层。 |
| 0 | Markdown 预览 | Markdown 文件里按：在旁边打开预览，焦点留在文件上，换文件时预览跟着换；再按一次关掉预览。资源管理器里选中 Markdown 按：打开它并开预览。 |
| . | 撤销 | 撤销编辑器里最近一次修改（误触改了文件时用）。 |
