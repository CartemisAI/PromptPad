# What every key does

[中文](keys.zh-CN.md) · Generated from the default layout by `scripts/make-keys-doc.py`; run it again after changing the layout.
The key map in the app (Fn+NumLock) shows the same thing.

## Claude

### Base layer

| Key | Does | Detail |
|---|---|---|
| Knob | Move cursor Back to box | Turn: move one character left or right. Press: put the cursor back in the message box. |
| Esc | Esc | Esc. Stops Claude's reply; press twice to go back to an earlier message. |
| Del | Delete word | Delete the word before the cursor (Option+Delete). |
| Tab | Next field | Tab: go to the next button, link or field. |
| Bksp | Delete | Delete the character before the cursor. |
| M1 | Claude | Switch to Claude from anywhere. |
| Num | To start | Jump to the start of the text or file (Command+↑). |
| / | Word ← | Move one word left (Option+←). |
| * | Word → | Move one word right (Option+→). |
| − | To end | Jump to the end (Command+↓). |
| M2 | ChatGPT | Switch to ChatGPT from anywhere. |
| 7 | Unused | Types nothing, so stray presses do no harm. |
| 8 | Page up | Scroll up one page. |
| 9 | Scroll up a little | Scroll the conversation a little; hold to keep going. Works wherever the cursor and pointer are. |
| + | New line | New line without sending (Shift+Return). |
| M3 | Cycle apps | Cycle through Chrome and VS Code. |
| 4 | Left | Cursor left one step. |
| 5 | Space | Space. |
| 6 | Right | Cursor right one step. |
| M4 | Hold for Command | Hold: the keypad holds Command. With a digit: switch session; with Enter: send later; turn the knob or press M3: pick an app. |
| 1 | Comma , | Types a comma “,” whatever the input method. |
| 2 | Page down | Scroll down one page. |
| 3 | Scroll down a little | Scroll the conversation a little; hold to keep going. Works wherever the cursor and pointer are. |
| Enter | Send | Send the message. |
| Fn | Fn layer | Hold for the Fn layer: panels, sessions and quick replies. It also holds Shift, so the key map can tell. |
| 0 | Voice | Tap to start and tap again to stop, or hold to talk and let go. M4+0 switches to macOS dictation. |
| . | Undo | Undo (Command+Z). |

### Holding Fn

| Key | Does | Detail |
|---|---|---|
| Knob | Brightness Backlight | Hold Fn and turn: backlight brightness. Press: backlight on / off. |
| Esc | Bluetooth 1 | Switch to Bluetooth device 1. |
| Del | Fwd delete word | Delete the word right of the cursor. |
| Tab | Previous field | Shift+Tab: back to the previous button, link or field. |
| Bksp | Fwd delete | Delete the character right of the cursor. |
| M1 | Switch mic | The first press shows the microphone list with the one in use highlighted; press again while it's up for the next one. It closes after 3 seconds. You can also pick one from the menu bar. |
| Num | Key map | Show or hide this key map; Esc also closes it. |
| / | Continue | Pastes and sends “Continue.” |
| * | Go ahead | Pastes and sends “Yes, go ahead.” |
| − | Run tests | Pastes and sends “Run the tests and fix any that fail.” |
| M2 | Bluetooth 2 | Switch to Bluetooth device 2. |
| 7 | Side Chat | Open a side chat to ask a question while the main session keeps working. |
| 8 | Previous session | Switch to the previous session. |
| 9 | New session | Start a new session. |
| M3 | 2.4G | Switch to the 2.4 GHz receiver. |
| 4 | Changes | Open the changes panel to see what Claude changed. |
| 5 | Mode menu | Open the mode menu, then choose Plan mode with a digit on the main keyboard (the keypad no longer types digits). |
| 6 | Terminal | Show or hide the terminal. |
| M4 | Switch window | Switch between windows of the same app (backwards). |
| 1 | Files | Open the files panel. |
| 2 | Next session | Switch to the next session. |
| 3 | Close panel | Close the current panel. |
| Enter | Send now | Sends the queued message now (Send now in Claude, Steer in ChatGPT). If the message is still in the box, it is queued first. |
| Fn | Holding | The Fn layer. |
| 0 | Side question | Types /btw at the start of the message box and starts voice: a side question that doesn't interrupt what Claude is doing. Press 0 to stop and Enter to send, or hold to talk and let go. |
| . | Redo | Redo (Command+Shift+Z): bring back what you undid. |

### Holding M4

| Key | Does | Detail |
|---|---|---|
| Knob | App switcher | Hold M4 and turn: pick an app in the app switcher; let go of M4 to switch. |
| 7 | Session 7 | Command+7: jump to session 7. |
| 8 | Session 8 | Command+8: jump to session 8. |
| 9 | Session 9 | Command+9: jump to session 9. |
| M3 | Next app | Select the next app in the app switcher. |
| 4 | Session 4 | Command+4: jump to session 4. |
| 5 | Session 5 | Command+5: jump to session 5. |
| 6 | Session 6 | Command+6: jump to session 6. |
| M4 | Holding | The keypad holds Command. |
| 1 | Session 1 | Command+1: jump to session 1. |
| 2 | Session 2 | Command+2: jump to session 2. |
| 3 | Session 3 | Command+3: jump to session 3. |
| Enter | Queue | While Claude or ChatGPT is working, the message waits until this turn ends. |
| 0 | Switch dictation | Switch between the app's own voice input and macOS dictation; remembered per app. |

## VS Code

### Base layer

| Key | Does | Detail |
|---|---|---|
| Knob | Scroll Open file | Turn: scroll the editor two lines per step; move up and down in the Explorer, lists and Cmd+P. Press: open the file selected in the Explorer. |
| Esc | Esc | Esc。 |
| Del | Off | Word delete does nothing in VS Code, so files can't change by accident. |
| Tab | Off | Tab does nothing in VS Code, so files can't change by accident. |
| Bksp | Off | Delete does nothing in VS Code, so files can't change by accident. |
| M1 | Claude | Switch to Claude from anywhere. |
| Num | To start | Jump to the start of the text or file (Command+↑). |
| / | Word ← | Move one word left (Option+←). |
| * | Word → | Move one word right (Option+→). |
| − | To end | Jump to the end (Command+↓). |
| M2 | ChatGPT | Switch to ChatGPT from anywhere. |
| 7 | Unused | Types nothing, so stray presses do no harm. |
| 8 | Page up | Scroll up one page. |
| 9 | Up one | In the Explorer: select the previous or next item. In the editor: move a line. |
| + | Next file | Open the next file in Explorer order; the preview follows. |
| M3 | Cycle apps | Cycle through Chrome and VS Code. |
| 4 | Left | Cursor left one step. |
| 5 | Off | Space does nothing in VS Code, so files can't change by accident. |
| 6 | Right | Cursor right one step. |
| M4 | Hold for Command | Hold: the keypad holds Command. With a digit: switch session; with Enter: send later; turn the knob or press M3: pick an app. |
| 1 | Off | Comma does nothing in VS Code, so files can't change by accident. |
| 2 | Page down | Scroll down one page. |
| 3 | Down one | In the Explorer: select the previous or next item. In the editor: move a line. |
| Enter | Open ⇄ Explorer | In the Explorer: open a file or expand a folder. In the editor or preview: back to the Explorer. In lists and Cmd+P: choose. Does nothing in the terminal. |
| Fn | Fn layer | Hold for the Fn layer: panels, sessions and quick replies. It also holds Shift, so the key map can tell. |
| 0 | Off | Voice is off in VS Code, so code can't change by accident. |
| . | Off | Undo does nothing in VS Code, so files can't change by accident. |

### Holding Fn

| Key | Does | Detail |
|---|---|---|
| Knob | Brightness Backlight | Hold Fn and turn: backlight brightness. Press: backlight on / off. |
| Esc | Bluetooth 1 | Switch to Bluetooth device 1. |
| M1 | Switch mic | The first press shows the microphone list with the one in use highlighted; press again while it's up for the next one. It closes after 3 seconds. You can also pick one from the menu bar. |
| Num | Key map | Show or hide this key map; Esc also closes it. |
| / | Sidebar | Show or hide the sidebar on the left. |
| * | Chat panel | Show or hide the chat panel on the right (Copilot and others). |
| − | Editor only | Keep only the Explorer and the editor: close the preview column, the terminal and the chat panel. |
| M2 | Bluetooth 2 | Switch to Bluetooth device 2. |
| 7 | Source control | Open source control to see what changed. |
| 8 | Go to symbol | List the headings and symbols in this file; choose with 9, 3 or the knob, Enter jumps there. |
| 9 | Terminal | Show or hide the terminal. |
| + | Previous file | Open the previous file in Explorer order. |
| M3 | 2.4G | Switch to the 2.4 GHz receiver. |
| 4 | Tab left | Switch to the tab on the left in this column. |
| 5 | Close tab | Close this tab. With unsaved changes you're asked first (Esc cancels); Fn+3 drops the changes instead. |
| 6 | Tab right | Switch to the tab on the right in this column. |
| M4 | Switch window | Switch between windows of the same app (backwards). |
| 1 | Explorer ⇄ editor | In the Explorer: back to the file you're reading. Anywhere else: jump to the Explorer. |
| 2 | Close other tabs | Keep only this tab; close the other tabs in this column. |
| 3 | Discard & close | Drop this file's unsaved changes, go back to the last saved version and close the tab without asking. For when a file got changed by accident. |
| Enter | Recent files | Open the recent files list: choose with 9, 3 or the knob, Enter opens. |
| Fn | Holding | The Fn layer. |
| 0 | Markdown preview | In a Markdown file: open the preview beside it; focus stays on the file and the preview follows when you switch files. Press again to close it. In the Explorer, with a Markdown file selected: open it with its preview. |
| . | Undo | Undo the last change in the file (for when a file got changed by accident). |
